# remote.it (solo test build)

Reach Home Assistant, and the devices on your home network, from anywhere through remote.it — no port forwarding, no
public address.

> **A test build, unsupported.** It is for remote.it's **solo** stage (https://app.solo.remote.it), for testing: it may change or
> break without notice, and remote.it support does not cover it. Home Assistant lists it only with **Advanced mode** on.

- **Home Assistant's web UI** as a remote.it service on this machine.
- **A gateway to your home network**: services pointing at your router, cameras, NAS — any machine Home Assistant's
  host reaches.
- A **remote.it panel** in the sidebar: the device's name, state and UID, a link to it in the portal, and a field for
  its registration code.

See the Documentation tab.
