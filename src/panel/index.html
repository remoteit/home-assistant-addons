Register this device

Paste a registration code from the remote.it portal (Add device). A code made with a service for Home Assistant gives you its web UI as soon as the device registers.

Home Assistant's web UI

To reach Home Assistant through remote.it, the device needs a service for it. In the portal, on this device: Add service — type HTTP, host 127.0.0.1, port 8123.

Your home network

This device can also be a gateway: add services whose host is another machine on your network (your router at 192.168.1.1, a camera, a NAS), and reach them as you reach Home Assistant.
